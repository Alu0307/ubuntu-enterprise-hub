# Ubuntu Enterprise Hub (UEH)

## Project Description
Ubuntu Enterprise Hub is a web-based Enterprise Support and Opportunity Management Platform designed to support small and medium enterprises (MSMEs).

## Project Objectives
- Allow users to register and log in.
- Allow MSMEs to submit service requests.
- Allow clients to track their requests.
- Display funding, tender and training opportunities.
- Allow clients to apply for opportunities.
- Provide an administration dashboard.

## User Roles
1. MSME Client
2. UEH Support Agent
3. UEH Administrator

## Technologies
- Python
- Django
- Django REST Framework
- React
- PostgreSQL
- Git and GitHub
